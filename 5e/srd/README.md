# The 5e System Reference Document 5.1 (complete)

This folder is a complete copy of the **System Reference Document 5.1** for the fifth edition of the world's oldest roleplaying game, as released by Wizards of the Coast under **CC-BY-4.0**. It's here so *Mutagen 5e* can be played and checked against the open rules without leaving the repository.

## Sources
- **Official text:** [`SRD_CC_v5.1.pdf`](SRD_CC_v5.1.pdf), downloaded unchanged from `https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf` (403 pages).
- **Markdown:** converted from that PDF by the *SRD 5.1 reForged* project (OldManUmby, https://github.com/OldManUmby/DND.SRD.Wiki, commit `cecde94`), which publishes the CC-BY-4.0 text as Markdown. We kept its folder layout and dropped only exact duplicates (its one-file-per-spell/monster/item copies and an Obsidian-wikilink copy of the spell lists). The A–Z files below hold the same text.
- **Integrity check:** 565 randomly sampled paragraphs were compared with the official PDF's text: 78% matched word for word; the rest differ only in PDF line-break hyphenation and list layout.
- No non-SRD Wizards of the Coast material is included anywhere in `5e/`.
